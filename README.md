# 差旅出行助手Test

一个多智能体差旅助手系统。项目由一个多智能体编排后端与一个旅行规划网页组成，用户在网页里选择目的地、勾选景点后即可与 Agent 自然语言对话，后端完成意图理解、信息收集、行程规划与知识问答，并把结果流式返回前端。

## 整体架构

系统采用 **Plan-and-Execute** 编排模式，把一次用户请求拆成「意图识别 → 编排调度 → 子智能体执行 → 结果聚合」四个阶段：

```
用户输入
   ↓
IntentionAgent（意图识别）
   ↓
OrchestrationAgent（按优先级并行调度）
   ↓
子智能体 Skills（事项收集 / 行程规划 / 联网查询 / 知识库问答 / 偏好管理 / 记忆查询）
   ↓
结果聚合 + 记忆更新 → 人类可读回复
```

## 核心设计

### 1. 意图识别（IntentionAgent）

基于 LLM 语义理解判断用户意图，不依赖关键词匹配。一次输入可能包含多个意图，模型输出结构化的调度决策：每个意图的置信度、关键实体、改写后的查询，以及要调用的子智能体清单与优先级。

### 2. 优先级并行调度（OrchestrationAgent）

子智能体按优先级分组执行：**同优先级并行、不同优先级串行依赖**。信息收集类任务（记忆查询、事项收集、偏好管理、联网查询、知识库检索）放在 Priority 1 并行执行，行程规划放在 Priority 2，等待前序信息就绪后再整合生成。

### 3. Skill 插件化 + 懒加载

所有子智能体以 Skill 插件的形式组织，通过 LazyAgentRegistry 动态扫描注册。系统启动时只加载意图识别所需的元数据，子智能体在首次被调度时才真正实例化，从而降低启动开销。

### 4. 两层记忆

- **短期记忆**：会话级滑动窗口，保存最近若干轮对话，用于上下文理解与意图消歧。
- **长期记忆**：按用户持久化，保存偏好、历史行程、聊天记录，支持跨会话访问；偏好支持「追加 / 覆盖」两种更新动作。

### 5. RAG 知识库

基于 Milvus Lite 向量库 + 本地 BGE 中文向量模型，把差旅政策、报销标准、预订指南等文档向量化后做语义检索，回答时附带知识来源。

### 6. 稳定性保障

- **熔断器**：连续失败后暂停调用 LLM，一段时间后半开试探恢复。
- **指数退避重试**：对超时、限流、5xx 等可重试错误自动重试。
- **健康检查**：实时探测 LLM 服务可用性。

## Web 集成

后端以 **OpenAI 兼容接口** 暴露：`POST /v1/chat/completions`（SSE 流式），前端沿用标准的 OpenAI 客户端协议即可接入，无需改动前端请求逻辑。

- 网页把用户当前选择的目的地、景点、出发地、行程日期等上下文随请求发给后端，后端将其注入意图识别的上下文。
- 前端用 `localStorage` 生成稳定的 `client_id`，经 `X-Client-Id` 头传入，后端以此作为用户标识缓存核心引擎，实现长期记忆跨会话保留。
- 同一套核心逻辑同时服务于命令行（`cli.py`）与 Web 服务（`server.py`）。

## 目录结构

```
agent/
├── core.py                  # 核心引擎：编排流程 + 结果渲染
├── server.py                # FastAPI 服务（OpenAI 兼容 SSE 接口）
├── cli.py                   # 命令行入口
├── config.py                # 配置（从环境变量读取密钥）
├── agents/                  # 意图识别、编排调度、插件注册
├── context/                 # 短期 / 长期记忆
├── utils/                   # 熔断、重试、JSON 解析、Skill 加载
├── .claude/skills/          # 子智能体插件
└── data/                    # 长期记忆与本地向量模型
web/
└── index.html               # 旅行规划网页（对话窗口 + 地图 + 景点）
```

## 快速开始

1. 在 `agent/` 下创建虚拟环境并安装依赖（Windows 可双击 `setup_env.bat`）。
2. 在 `agent/.env` 中配置 `LLM_API_KEY` 等环境变量（参考 `.env.example`）。
3. 启动后端：`uvicorn server:app --host 127.0.0.1 --port 8000`。
4. 打开 `web/index.html`，在对话窗口提问或勾选景点生成路线。
